# V6.0 Experimental Space

Цей простір для експериментів з наступними концепціями:

## Теорема згортання Кале (Gaal's Folding Theorem)

**Гіпотеза:** Сама решітка (block vector) - це місце під "гліф", а не гліф сам
по собі.

### Ключові операції:

1. **Згортання/Розгортання** (Folding/Unfolding)
2. **Обертання** (Rotation)
3. **Пульсації** (Pulsation)
4. **Хвилі** (Waves)

### Розширена фаза:

Фаза більше не одне число, а вектор з 2+ показниками:

- θ (poloidal) - Intent axis
- φ (toroidal) - Truth axis
- Можливо ще: ψ (radial), ω (temporal)
